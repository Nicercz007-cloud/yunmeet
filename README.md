# 云聚会议 YunMeet

一个**单文件**的浏览器视频会议网站：免注册、不限时长、仅主持人可投屏。整个网站就是一个 `yunmeet.html`，扔到任何 HTTPS 托管上（GitHub Pages / Netlify / Vercel 均可），参会者用浏览器打开链接即可开会。

> 中文使用教程见 [使用说明.md](使用说明.md)。

## 特性

- **零注册、零安装**：浏览器打开链接就进会，音视频在参会者之间点对点直连（WebRTC），不经服务器存流。
- **单文件、零外部 CDN**：PeerJS 已内置在 HTML 里，国内网络直接可用；唯一外部依赖是免费的公共信令服务。
- **会议号 + 邀请链接**：6 位会议号；`?room=XXXXXX` 链接自动预填。
- **主持人管控**：投屏（仅主持人）、锁定会议、静音/移出成员、结束全体会议。
- **会中能力**：宫格画面、说话人指示、文字聊天、成员面板、会议计时、直连/中继与延迟显示。
- **弱网友好（v4.1）**：上行码率随丢包/带宽自适应（快降慢升）、摄像头 24 帧、投屏"流畅优先"编码。
- **同步可靠（v4.1）**：数据通道星型拓扑（经主持人中转）+ 8 秒全量名单对齐 + 4 秒心跳 + 断线自动重连 + 媒体死链自动重拨。

## 快速开始

本地测试（浏览器要求 `https://` 或 `localhost` 才能开摄像头）：

```bash
# 在本目录任选其一
python -m http.server 8944     # 然后访问 http://localhost:8944/yunmeet.html
npx serve -l 8944
```

Windows 用户直接双击 `启动云聚会议.bat`。

部署到公网：把 `yunmeet.html` 拖到 [Netlify Drop](https://app.netlify.com/drop)，或推到 GitHub 后开启 Pages（Settings → Pages → main / root），得到 HTTPS 网址后发给队友即可。

## 架构（30 秒版）

```
        信令服务（PeerJS 公共云，仅用于互相找到对方）
                    │
        ┌───────────┼───────────┐
        │      主持人(Hub)      │        ← 数据通道全部指向主持人
     成员 A     成员 B    成员 C       ← 媒体流成员两两直连（mesh）
```

- **数据**（聊天/状态/名单/心跳）：星型拓扑，主持人是唯一裁决者，每 8 秒广播全量名单，各端幂等对齐 —— 状态漂移无从产生。
- **媒体**：WebRTC mesh 点对点直连；打洞优先用国内可达 STUN，失败时才落到 TURN 中继并自动降码率。
- **离开判定**：仅主持人裁决（数据通道关闭 / 心跳超时 20s + 媒体链路死亡双确认），广播 `left` 通报全员。

## 配置

文件开头常量可按需调整：

| 常量 | 默认 | 说明 |
|---|---|---|
| `SHARE_MAX_W / SHARE_MAX_H` | 1280 / 720 | 投屏采集分辨率上限 |
| `SHARE_FPS` | 15 | 投屏帧率 |
| `SHARE_BITRATE` | 3000000 | 投屏直连码率上限 |
| `vidCap`（`S.vidCap` 初始值） | 1500000 | 视频码率自适应起点 |

## 已知限制

- 点对点 mesh 上行随人数放大，建议 **8 人以内**（硬上限 12）。
- 屏幕共享仅桌面浏览器支持；手机可正常入会、观看投屏。
- 「静音成员」是对端自觉服从的指令，无中心服务器强制执行（纯浏览器方案的固有限制）。
- 依赖免费公共信令服务，极小概率拥堵或被严格企业网络拦截。
- 6 位会议号无密码，敏感会议不建议使用。
